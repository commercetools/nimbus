Initial release of `@commercetools/nimbus-viz` — a data-visualization library
for Nimbus. Ships 31 React chart components (line, bar, stacked/grouped bar,
area, streamgraph, donut, treemap, funnel, scatter, bubble, radar, parallel
coordinates, heatmap, calendar heatmap, cohort triangle, RFM grid, histogram,
box plot, sankey, waterfall, dumbbell, slope, bump, pareto, control chart,
bullet, gauge, stat card, sparkline, and a data-table fallback), each themed
from Nimbus design tokens with light and dark palettes, a hover tooltip on every
plot with inspectable marks, `role="img"` accessibility, and a
`ResponsiveContainer` for fluid or aspect-ratio sizing. Composable overlays
(reference line, target marker, trend line, threshold/confidence bands, error
bars, benchmark series) layer annotations over the axis-based charts.
