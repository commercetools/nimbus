Layout decides where elements go and how much space they take. In Nimbus you
place elements with layout components such as `Stack` and `SimpleGrid`, set the
space between them with spacing tokens, and set sizes with size tokens. Start
with `Stack`. It fits most layouts.

## Stack: items in one direction

`Stack` places its children in a column, or in a row with `direction="row"`.
`gap` sets the space between the children. `align` sets the alignment across
the direction, `justify` along it, and `wrap` lets the children move to a new
line when there is no room.

```jsx live-dev
import { Box, Stack } from "@commercetools/nimbus";

const App = () => (
  <Stack direction="row" gap="400" align="center">
    <Box padding="400" backgroundColor="primary.3">Item 1</Box>
    <Box padding="600" backgroundColor="primary.3">Item 2</Box>
    <Box padding="400" backgroundColor="primary.3">Item 3</Box>
  </Stack>
);
```

## SimpleGrid and Grid: columns

`SimpleGrid` places its children in columns of the same width. Set the number
of columns with `columns`. For items that span several columns or rows, use
`Grid` with `Grid.Item` and props such as `templateColumns` and `colSpan`.

```jsx live-dev
import { Box, Grid, SimpleGrid, Stack } from "@commercetools/nimbus";

const App = () => (
  <Stack gap="600">
    <SimpleGrid columns={3} gap="400">
      <Box padding="400" backgroundColor="info.3">1</Box>
      <Box padding="400" backgroundColor="info.3">2</Box>
      <Box padding="400" backgroundColor="info.3">3</Box>
    </SimpleGrid>
    <Grid templateColumns="repeat(3, 1fr)" gap="400">
      <Grid.Item colSpan={2}>
        <Box padding="400" backgroundColor="positive.3">Spans 2 columns</Box>
      </Grid.Item>
      <Box padding="400" backgroundColor="positive.3">1 column</Box>
    </Grid>
  </Stack>
);
```

## Flex and Box

`Flex` is a flex container with props such as `direction`, `align` and `wrap`.
Use it when each child needs to grow or shrink in its own way: each child sets
this with its own style props `flexGrow`, `flexShrink` and `flexBasis`. `Box` is a plain
element that takes all style props. Use it for one element that needs
padding, a size or a color.

| You want…                                     | Use          |
| --------------------------------------------- | ------------ |
| Items in a row or a column with equal space   | `Stack`      |
| Columns of the same width                     | `SimpleGrid` |
| Items that span several columns or rows       | `Grid`       |
| Control over how each item grows or shrinks   | `Flex`       |
| One element with padding, a size or a color   | `Box`        |

## Sizes

Set `width`, `height`, `minWidth` and `maxWidth` with
[size tokens](/home/design-tokens/sizes): numbers such as `400`, names such as
`md` or `prose`, fractions such as `1/2`, and `full` for the whole width. See
[Use the full width](/learn/how-do-i/use-the-full-width). To cut off text that
is too long, see [Truncate text](/learn/how-do-i/truncate-text).

## Screen sizes

To change a value by screen size, give the prop an object instead of a single
value. This works for style props and for layout props such as `direction` and
`gap`.

```jsx live-dev
import { Box, Stack } from "@commercetools/nimbus";

const App = () => (
  <Stack
    direction={{ base: "column", md: "row" }}
    gap={{ base: "200", md: "600" }}
  >
    <Box padding="400" backgroundColor="warning.3">Item 1</Box>
    <Box padding="400" backgroundColor="warning.3">Item 2</Box>
  </Stack>
);
```

The keys are [breakpoints](/home/design-tokens/other/breakpoints): `sm`
(480px), `md` (768px), `lg` (1024px), `xl` (1280px) and `2xl` (1536px). Each
breakpoint is a minimum width: a value for `md` applies from 768px up, until a
larger key takes over. `base` applies to every width where no other key
applies. So write the value for the smallest screen as `base`, and add changes
for larger screens.

`SimpleGrid` can also adapt without breakpoints: with `minChildWidth`, it adds
or removes columns to fit the space.

```jsx live-dev
import { Box, SimpleGrid } from "@commercetools/nimbus";

const App = () => (
  <SimpleGrid minChildWidth="2xs" gap="400">
    <Box padding="400" backgroundColor="neutral.3">1</Box>
    <Box padding="400" backgroundColor="neutral.3">2</Box>
    <Box padding="400" backgroundColor="neutral.3">3</Box>
    <Box padding="400" backgroundColor="neutral.3">4</Box>
  </SimpleGrid>
);
```

## What you cannot change

The breakpoints are the same in every app. You cannot add a breakpoint or move
one to another width.

## When nothing fits

If no size token fits, use a raw size on that one element and mark it as a
[one-off](/learn/rules):

```jsx live-dev
import { Box } from "@commercetools/nimbus";

const App = () => {
  // nimbus-one-off: the preview must have the 3:2 width of the print layout
  const previewWidth = "360px";

  return <Box width={previewWidth} height="1600" backgroundColor="neutral.3" />;
};
```
