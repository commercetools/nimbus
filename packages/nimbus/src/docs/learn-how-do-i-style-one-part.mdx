You want to change one part of a component, for example only the header of a
card. In Nimbus, each part of a compound component is its own component, such as
`Card.Header`. Set style props with tokens on that part. The other parts keep
their look. This is step 2 of [Customize in three steps](/foundations/customize-in-three-steps).

```jsx live-dev
import { Card, Text } from "@commercetools/nimbus";

const App = () => (
  <Card.Root>
    <Card.Header backgroundColor="primary.2" color="primary.11">
      Project settings
    </Card.Header>
    <Card.Body>
      <Text>Only the header has a new background and text color.</Text>
    </Card.Body>
  </Card.Root>
);
```

## Why it works

Parts such as `Card.Header` take style props, like `Box`. A style prop changes
only the property that you set, and the part keeps all its other styles.

Class names and data attributes are not part of the public API of a component,
so they can change in any release. A CSS selector such as `svg` can also match
more elements than the one you want. See [Styling](/learn/concepts/styling) and
[Component structure](/learn/concepts/component-structure).

## When nothing fits

If the design needs a value that no token has, set the raw value on the part.
Mark it as a [one-off](/learn/rules) with the reason, so that your team can find it later.

```jsx live-dev
import { Card, Text } from "@commercetools/nimbus";

const App = () => (
  <Card.Root>
    {/* nimbus-one-off: the header must match the 72px height of the campaign banner */}
    <Card.Header minHeight="72px">Spring campaign</Card.Header>
    <Card.Body>
      <Text>The header is as high as the banner above it.</Text>
    </Card.Body>
  </Card.Root>
);
```
