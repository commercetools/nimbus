## Choose a color

A color is a palette and a step, such as `primary.3` or `critical.9`. Use a
**semantic palette** when the color has a meaning, for example `critical` for an
error. Components take a palette with the `colorPalette` prop.

```tsx
<Box bg="primary.3" color="primary.11" borderColor="primary.7">
  content
</Box>

<Button colorPalette="critical" variant="solid">
  Delete
</Button>
```

See [Colors](/home/design-tokens/colors) for all palettes and what each step is
for.

## Dark mode

Every color step has two values: one for light mode and one for dark mode. The
token name stays the same. So your components and your own styles follow the
color mode, and you do not need a separate design for dark mode.

Only `blackAlpha` and `whiteAlpha` keep the same value in both modes. For a gray
that follows the mode, use `neutral`.

## Switch the color mode

`NimbusProvider` manages the color mode. It accepts the props of the
[`next-themes`](https://github.com/pacocoursey/next-themes) provider, such as
`defaultTheme` and `enableSystem`.

```tsx
import { NimbusProvider } from "@commercetools/nimbus";

<NimbusProvider defaultTheme="dark" enableSystem={false}>
  <App />
</NimbusProvider>;
```

To let people change the mode, use the `useColorMode` hook. It is marked
experimental, so it may change.

```tsx
import { Button, useColorMode } from "@commercetools/nimbus";

function ThemeToggle() {
  const { colorMode, toggleColorMode } = useColorMode();

  return (
    <Button onClick={toggleColorMode}>
      Current mode: {colorMode}
    </Button>
  );
}
```
