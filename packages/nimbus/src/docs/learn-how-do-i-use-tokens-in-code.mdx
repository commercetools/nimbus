You write CSS yourself, or you need a token value in JavaScript, for example for
a chart or for a component from another library. Every Nimbus token is also a
CSS variable. In JavaScript, `system.token` returns the token.

## In CSS

The variable name is `--nimbus-`, then the token group, then the token name,
with dashes instead of dots. The token groups have plural names, such as
`colors`, `radii` and `sizes`.

| Token              | CSS variable                     |
| ------------------ | -------------------------------- |
| `spacing.400`      | `var(--nimbus-spacing-400)`      |
| `colors.primary.9` | `var(--nimbus-colors-primary-9)` |
| `colors.fg.subtle` | `var(--nimbus-colors-fg-subtle)` |
| `radii.200`        | `var(--nimbus-radii-200)`        |
| `fontSizes.350`    | `var(--nimbus-font-sizes-350)`   |
| `zIndex.sticky`    | `var(--nimbus-z-index-sticky)`   |

```css
.campaign-banner {
  padding: var(--nimbus-spacing-400);
  border-radius: var(--nimbus-radii-200);
  background-color: var(--nimbus-colors-primary-3);
}
```

The color variables follow the color mode, like the colors of the components.

## In JavaScript

`system` is exported from `@commercetools/nimbus`. Call `system.token` with the
token group and the token name.

```jsx live-dev
import { Stack, Text, system } from "@commercetools/nimbus";

const App = () => (
  <Stack gap="200">
    <Text>spacing.400: {system.token("spacing.400")}</Text>
    <Text>colors.primary.9: {system.token("colors.primary.9")}</Text>
    <Text>colors.fg.muted: {String(system.token("colors.fg.muted"))}</Text>
  </Stack>
);
```

- For a token with one value, such as spacing, you get the value: `16px`.
- For a color, you get the CSS variable, because the value depends on the color
  mode.
- For a name that does not exist, you get `undefined`.

`system.token.var("spacing.400")` always returns the CSS variable.

## Why it works

Style props use the same CSS variables. So your own CSS and the Nimbus
components show the same values, also after a token changes. See
[Tokens and colors](/learn/concepts/tokens-and-colors).
