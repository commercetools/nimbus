Nimbus has three ways to change how a component looks. Use the first one that
fits your task.

## 1. Theming props

Components offer props such as `variant`, `size`, `textStyle` and
`colorPalette`. They apply a ready-made look from the Nimbus design language.
Use them for every standard case.

```tsx
import { Button } from "@commercetools/nimbus";

<Button variant="solid" colorPalette="primary" size="lg">
  Save
</Button>;
```

See [Theming](/styling/guides/theming) for all theming props.

## 2. Style props with tokens

When theming props do not cover your need, set a style prop on that one
component. Give it a token, not a raw value. The result stays consistent with
the rest of the design system.

```tsx
import { Box } from "@commercetools/nimbus";

<Box padding="400" backgroundColor="primary.2" borderRadius="full" />;
```

See [Style Props](/home/style-props) for the full list and
[Design Tokens](/home/design-tokens) for the values.

## 3. Responsive values

Pass an object to a style prop or a theming prop to change the value by screen
size.

```tsx
import { Stack } from "@commercetools/nimbus";

<Stack direction={{ base: "column", md: "row" }} gap="400" />;
```

See [Responsive styling](/styling/guides/responsive-styling).
