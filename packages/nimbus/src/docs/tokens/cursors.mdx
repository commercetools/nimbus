Cursor tokens name the mouse cursor by the kind of element, not by the shape of
the cursor. `cursor="button"` shows the cursor that Nimbus uses for buttons.
There are eight tokens, and each one sets one of three CSS cursors: `pointer`,
`default` or `not-allowed`.

## Choose a cursor

Use the token that names your element, such as `cursor="switch"` for an element
that works as a switch. The value is set in one place, so all elements that use
the same token show the same cursor.

> [!NOTE]\
> Menu and Slider do not use these tokens. Menu items and the track of Slider
> set `pointer`, but the tokens `menuitem` and `slider` set `default`
> ([issue #2146](https://github.com/commercetools/nimbus/issues/2146)).

### Disabled elements

For a disabled element, use the layer style `disabled` instead of the cursor
alone. It sets `cursor: not-allowed` and `opacity: 0.5`
(`packages/nimbus/src/theme/layer-styles.ts`), so the element also looks
disabled.

```tsx
// In a recipe
_disabled: {
  layerStyle: "disabled",
},
```

### Cursors without a token

There are no tokens for other cursors, such as the cursor for text or for
dragging. The recipes of Nimbus components set the CSS value for them:

| Cursor                        | Nimbus components that use it    |
| ----------------------------- | -------------------------------- |
| `grab` and `grabbing`         | DataTable, DraggableList, Tree   |
| `text`                        | TextInput, SearchInput, ComboBox |
| `col-resize` and `row-resize` | DataTable, Splitter              |

For all CSS cursors, see
[MDN: cursor](https://developer.mozilla.org/en-US/docs/Web/CSS/cursor).

## Use cursors in code

Cursor tokens work on the `cursor` style prop.

```tsx
// A Box
<Box cursor="button" />

// In a recipe
base: {
  cursor: "button",
},
```

A cursor only changes how an element looks under the mouse pointer. An element
that works as a button also needs the role, the keyboard support and the focus
of a button
([WAI-ARIA Authoring Practices: Button](https://www.w3.org/WAI/ARIA/apg/patterns/button/)).
[Button](/components/buttons/button) has all of that, so use it when you can.

For the full list of props, see
[Style props: Interactivity](/home/style-props/interactivity).

### CSS variables

Every token is also a CSS variable, such as `var(--nimbus-cursor-button)`, for
styles that you write yourself.

### Editor support

With the design token TypeScript plugin, autocomplete shows the value next to
the token. See
[Installation](/home/getting-started/installation#design-token-autocomplete-optional)
for how to set it up.

## Values that Nimbus components use

Most recipes of Nimbus components set the CSS value: `pointer` (22 times),
`default` (11 times) and `not-allowed` (6 times). The token `button` is used 8
times, in Avatar, Button, NumberInput, Select and TagGroup, and `menuitem` once,
in Select. 26 recipes use the layer style `disabled`.
