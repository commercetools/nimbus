There are four border tokens, from `solid-25` (1px) to `solid-100` (4px). As
with the [spacing](/home/design-tokens/spacing) tokens, the number is the pixel
value times 25.

> [!IMPORTANT]\
> Looking for rounded corners? Those use the [radii](/home/design-tokens/radii)
> tokens. Border tokens set only the width and the style of the line.

## Border tokens

> [!WARNING]\
> Always set `borderColor` next to a border token. A border token sets the CSS
> `border` shorthand. Its value has no color, so the shorthand sets the color to
> the text color
> ([MDN: border](https://developer.mozilla.org/en-US/docs/Web/CSS/border)).
> `<Box border="solid-25" />` draws a line in the text color. Write
> `<Box border="solid-25" borderColor="border" />`.

The samples use `borderColor="border.emphasized"`.

## Border colors

The color `border` is the default border color of Nimbus. Nimbus sets it on
every element (`--global-color-border` in
`packages/nimbus/src/theme/global-css.ts`), so it applies when an element has a
border width but no border token.

Each border color points to a step of a palette, as the table shows. Steps 6 to
8 of every palette are the border steps, so you can also use a step of another
palette, such as `primary.7`. See [Steps](/home/design-tokens/colors#steps) on
the Colors page.

The samples use `border="solid-25"`.

<BordersScale kind="colors" />

`border.subtle` and `border.muted` are not weaker than `border`: `border.subtle`
is the same color, and `border.muted` is one step stronger.

## Choose a border

| You want                                                | Use                                       | Example                                                     |
| ------------------------------------------------------- | ----------------------------------------- | ----------------------------------------------------------- |
| A thin line around an element, such as a card           | `solid-25` and `border`                   | `<Box border="solid-25" borderColor="border" />`            |
| A line on one side, for example between rows            | `solid-25` on one side                    | `<Box borderBottom="solid-25" borderColor="border" />`      |
| A stronger line                                         | `border.emphasized`                       | `<Box border="solid-25" borderColor="border.emphasized" />` |
| A line that shows a status                              | A status color, such as `border.critical` | `<Box border="solid-25" borderColor="border.critical" />`   |
| A thicker line, for a small control that must stand out | `solid-50`                                | `<Box border="solid-50" borderColor="border.emphasized" />` |

## Use borders in code

Border tokens work on the style props for borders.

| You draw                                       | Props                                                    |
| ---------------------------------------------- | -------------------------------------------------------- |
| A line on all sides                            | `border`                                                 |
| A line on one side                             | `borderTop`, `borderRight`, `borderBottom`, `borderLeft` |
| Lines on the left and right, or top and bottom | `borderX`, `borderY`                                     |
| A line at the start or end of the text line    | `borderStart`, `borderEnd`                               |
| The color of the line                          | `borderColor`                                            |

Start and end follow the direction of the text: in a right-to-left language, the
start is on the right
([MDN: CSS logical properties](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_logical_properties_and_values)).

```tsx
// A line around a card
<Box border="solid-25" borderColor="border" borderRadius="300" />

// A separator below a header
<Box borderBottom="solid-25" borderColor="border" />

// A thicker line in a status color
<Box border="solid-50" borderColor="border.critical" />

// In a recipe
base: {
  border: "solid-25",
  borderColor: "colorPalette.6",
}
```

For the full list of props, see [Style props: Border](/home/style-props/border).

### Change the width in a state

There are no tokens for the width alone. To change the width, for example when
an element is selected, set a border token and its color again in that state:

```tsx
// In a recipe
base: {
  border: "solid-25",
  borderColor: "border",
},
_selected: {
  border: "solid-50",
  borderColor: "primary.9",
},
```

### Borders and the size of an element

> [!NOTE]\
> Nimbus uses `box-sizing: border-box` for every element. The border is part of
> the width and the height that you set. A `100px` wide box with a `solid-25`
> border has 98px for the padding and the content.

### CSS variables

Every token is also a CSS variable, such as `var(--nimbus-borders-solid-25)`,
and every border color too, such as `var(--nimbus-colors-border-emphasized)`.

### Editor support

With the design token TypeScript plugin, autocomplete shows the value next to
the token. See
[Installation](/home/getting-started/installation#design-token-autocomplete-optional)
for how to set it up.

## Values that Nimbus components use

In the recipes of Nimbus components, `solid-25` is the most common border token
(19 times). Calendar, Select, ComboBox and ListBox, for example, use it on one
side only, with `borderBottom`. `solid-50` is used 7 times, for Checkbox,
Switch, Slider, Kbd, Steps and ListBox. `solid-75` and `solid-100` are not used.
