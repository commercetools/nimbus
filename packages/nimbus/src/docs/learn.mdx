These pages teach how to build UIs with Nimbus. They start with a small screen
and each page builds on the one before it, so read them in order.

1. [Build your first screen](/learn/build-your-first-screen): put components
   together.
2. [Arrange content](/learn/arrange-content): place and space elements with
   Stack, Flex and the grids.
3. [Adjust the look](/learn/adjust-the-look): change how elements look with
   theming props, style props and tokens.
4. [Adapt to screen size](/learn/adapt-to-screen-size): change layout and
   styling by screen size.
5. [Colors and dark mode](/learn/colors-and-dark-mode): choose colors and switch
   the color mode.
6. [Go further](/learn/go-further): CSS variables, the parts of a component, and
   what you cannot change.

Looking for a value or a prop? The [design tokens](/home/design-tokens) and the
[style props](/home/style-props) list every one.
