These pages teach how to build screens with Nimbus. They start with the basics
and each page builds on the one before it, so read them in order.

1. [Layout and styling](/learn/layout-and-styling): what each one does, and
   which Nimbus tools belong to which.
2. [Layout basics](/learn/layout-basics): place and space elements with Stack,
   Flex and the grids.
3. [Styling basics](/learn/styling-basics): change how elements look with
   theming props, style props and tokens.
4. [Responsive design](/learn/responsive-design): change layout and styling by
   screen size.
5. [Colors and dark mode](/learn/colors-and-dark-mode): choose colors and
   switch the color mode.
6. [Going further](/learn/going-further): CSS variables, the parts of a
   component, and what you cannot change.

Looking for a value or a prop? The **Reference** section lists every
[design token](/home/design-tokens) and every [style prop](/home/style-props).
