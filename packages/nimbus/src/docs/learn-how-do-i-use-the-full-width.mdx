A component is narrower than its container, and you want it to fill the whole
width. In Nimbus, set `width="full"` on the component. `full` is a size token,
and it means 100% of the parent.

```jsx live-dev
import { Button, Stack } from "@commercetools/nimbus";

const App = () => (
  <Stack align="start" gap="400" maxWidth="md">
    <Button variant="outline">Sized to its content</Button>
    <Button variant="outline" width="full">
      Uses the full width
    </Button>
  </Stack>
);
```

## Why it works

A column `Stack` and a `FormField` stretch their children, so inputs such as
`TextInput` and also a `Button` fill the width there. A `Stack` stops doing
this when you set `align`, as `align="start"` does in the example. Then, and in
parents that do not stretch, such as a `Box`, a `Button` keeps the width of its
content and needs `width="full"`.

`LocalizedField` always keeps the width of its content, so it needs
`width="full"` in every parent.

See [Layout](/learn/concepts/layout) and the
[size tokens](/home/design-tokens/sizes).
