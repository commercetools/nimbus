## Overview

Use `BarChart` to compare values across categories, for example visitors per month or orders per channel. Bars are easy to read and compare, because the eye compares their lengths.

> [!WARNING]\
> **Experimental.** `BarChart` is experimental in this first release and may
> change in a later version.

`BarChart` needs two peer dependencies that are not installed with Nimbus:
`recharts` and `react-is`. Install both:

```bash
pnpm add recharts react-is
```

npm and yarn also work (`npm install recharts react-is`,
`yarn add recharts react-is`). Nimbus accepts `recharts` version `^3.10.1` or
newer in the same major version.

A chart is given the rows of data, the field for the x axis, the series to draw,
and a label and color for each series. It fills the width of its container and
has a default aspect ratio. The look is minimal: light grid lines, no axis lines,
and a tooltip with the values of one data point.

To mix bars, lines and areas in one chart, use `Chart`.

## Variables

### One series

A chart with one series does not show a legend by default. Set `showLegend` to
show it.

```jsx live
const App = () => {
  const data = [
    { month: "Jan", desktop: 186, mobile: 80 },
    { month: "Feb", desktop: 305, mobile: 200 },
    { month: "Mar", desktop: 237, mobile: 120 },
    { month: "Apr", desktop: 273, mobile: 190 },
    { month: "May", desktop: 209, mobile: 130 },
  ];
  return (
    <BarChart
      aria-label="Desktop visitors per month"
      data={data}
      xAxisKey="month"
      series={["desktop"]}
      config={{ desktop: { label: "Desktop", palette: "ctviolet" } }}
    />
  );
};
```

### Several series

With two or more series the legend is always shown. Each series has a `label`
and an optional `palette` in `config`.

```jsx live
const App = () => {
  const data = [
    { month: "Jan", desktop: 186, mobile: 80 },
    { month: "Feb", desktop: 305, mobile: 200 },
    { month: "Mar", desktop: 237, mobile: 120 },
    { month: "Apr", desktop: 273, mobile: 190 },
    { month: "May", desktop: 209, mobile: 130 },
  ];
  return (
    <BarChart
      aria-label="Visitors per month"
      data={data}
      xAxisKey="month"
      series={["desktop", "mobile"]}
      config={{
        desktop: { label: "Desktop", palette: "ctviolet" },
        mobile: { label: "Mobile", palette: "orange" },
      }}
    />
  );
};
```

### Stacked

By default the series are side by side. Set `stacked` to put them on top of each other,
so the chart also shows the total of each category.

```jsx live
const App = () => {
  const data = [
    { month: "Jan", desktop: 186, mobile: 80 },
    { month: "Feb", desktop: 305, mobile: 200 },
    { month: "Mar", desktop: 237, mobile: 120 },
    { month: "Apr", desktop: 273, mobile: 190 },
    { month: "May", desktop: 209, mobile: 130 },
  ];
  return (
    <BarChart
      aria-label="Visitors per month, stacked"
      data={data}
      xAxisKey="month"
      series={["desktop", "mobile"]}
      stacked
      config={{
        desktop: { label: "Desktop", palette: "ctviolet" },
        mobile: { label: "Mobile", palette: "orange" },
      }}
    />
  );
};
```

### Grid

Horizontal grid lines are shown by default. Set `showGrid={false}` to hide them
when the values are easy to read from the tooltip or from labels around the chart.

```jsx live
const App = () => {
  const data = [
    { month: "Jan", desktop: 186, mobile: 80 },
    { month: "Feb", desktop: 305, mobile: 200 },
    { month: "Mar", desktop: 237, mobile: 120 },
    { month: "Apr", desktop: 273, mobile: 190 },
    { month: "May", desktop: 209, mobile: 130 },
  ];
  return (
    <BarChart
      aria-label="Visitors per month, without grid"
      data={data}
      xAxisKey="month"
      series={["desktop", "mobile"]}
      showGrid={false}
      config={{
        desktop: { label: "Desktop" },
        mobile: { label: "Mobile" },
      }}
    />
  );
};
```

### States

Set `isLoading` to show a placeholder while the data loads. An empty `data` array
shows the text "No data to display".

```jsx live
const App = () => (
  <Stack direction="column" gap="400">
    <BarChart
      aria-label="Loading chart"
      data={[]}
      xAxisKey="month"
      series={["desktop"]}
      config={{ desktop: { label: "Desktop" } }}
      isLoading
    />
    <BarChart
      aria-label="Empty chart"
      data={[]}
      xAxisKey="month"
      series={["desktop"]}
      config={{ desktop: { label: "Desktop" } }}
    />
  </Stack>
);
```

## Colors

Each series has a color. Choose it with the name of a palette in `config`, for
example `"ctviolet"` or `"orange"`. Only the 23 chart palettes are accepted:
blue, bronze, brown, crimson, ctviolet, cyan, gold, grass, gray, green, indigo, iris, jade, orange, pink, plum, purple, red, ruby, slate, teal, tomato, violet.

Seven palettes are not available, because their solid color is light and has a
black contrast color: amber, lime, mint, sky, yellow, ctyellow and ctteal.

When a series has no `palette`, it gets the next palette of the default order:
ctviolet, orange, teal, crimson, blue, grass, plum, bronze, cyan, red and slate.
A chart with more than 11 series uses the same order again from the start.

A chart uses the solid color of the palette. Only the lightness changes, and
only as much as needed so the color has at least 3:1 contrast against the `bg`
color of the current color mode. Colors are checked against `bg` only. Place
charts on `bg`. On gray or tinted surfaces, a few palettes can have a contrast
a little below 3:1.

## Guidelines

### Best practices

- Write an `aria-label` that says what the chart shows and for which period.
- Keep the number of series low. The default order has 11 palettes that are easy
  to tell apart; more series reuse colors.
- Use short, clear series labels. They appear in the legend and the tooltip.
- Place the chart on the `bg` color so the contrast checks apply.

### When to use

> [!TIP]\
> Use `BarChart` for categories you want to compare, such as channels, regions or months with few values.

> [!CAUTION]\
> Do not use `BarChart` for a trend over many points (use a line chart), or parts of one total with many categories.

## Accessibility

- Every chart needs an `aria-label` that says what the chart shows, for example
  "Visitors per month".
- Keyboard: Tab moves focus to the chart. ArrowLeft and ArrowRight move between
  the data points and show the tooltip. Enter hides the tooltip and shows it
  again.
- The tooltip is a live region, so a screen reader announces the values of the
  active data point.
- The legend is always shown for two or more series, so color is never the only
  way to tell series apart. `showLegend` only matters for a chart with one
  series.
- Bars that touch are separated by a 2 px stroke in the page color, so each bar
  has a visible edge.
- The draw animation is off by default when the person prefers reduced motion.
  Use `isAnimationActive` to set it yourself.
