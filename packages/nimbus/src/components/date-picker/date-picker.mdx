## Overview

Date picker can be simple or complex, allowing users to select a single date and
or specific times. There are two offered sizes, the default being medium for
most use cases.

## Variables

Get familiar with the features.

### Visual options

#### Medium

```jsx live
 const App = () => <DatePicker size="md" aria-label="Enter a date" width="1/3" />
```

#### Small

```jsx live
 const App = () => <DatePicker size="sm" aria-label="Enter a date" width="1/3" />
```
