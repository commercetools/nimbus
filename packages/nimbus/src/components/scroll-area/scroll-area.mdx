## Overview

ScrollArea constrains content within a fixed region and provides themed
scrollbar overlays that replace native browser scrollbars. By default the
scrollbar appears when the pointer enters the area or when the content scrolls,
then hides again after a short idle delay — while the pointer stays inside,
only scrolling brings it back, so a resting reader is not distracted. The
component is keyboard accessible — when content overflows, the area becomes
focusable via Tab and scrollable with arrow keys.

## Variables

Get familiar with the features.

### Orientation

Control which axes are scrollable. The default is `both`, so overflow on
either axis surfaces a visible scrollbar.

```jsx live
const App = () => (
  <Stack gap="600">
    <Box>
      <Text fontSize="sm" mb="200" fontWeight="bold">Both (default)</Text>
      <ScrollArea maxH="120px" maxW="300px" scrollbarVisibility="always">
        <Box whiteSpace="nowrap">
          {Array.from({ length: 15 }, (_, i) => (
            <Text key={i} fontSize="sm">{"Bidirectional content ".repeat(15)}</Text>
          ))}
        </Box>
      </ScrollArea>
    </Box>
    <Box>
      <Text fontSize="sm" mb="200" fontWeight="bold">Vertical</Text>
      <ScrollArea maxH="120px" w="300px" orientation="vertical" scrollbarVisibility="always">
        {Array.from({ length: 15 }, (_, i) => (
          <Text key={i} fontSize="sm">Line {i + 1}: Sample content for vertical scrolling.</Text>
        ))}
      </ScrollArea>
    </Box>
    <Box>
      <Text fontSize="sm" mb="200" fontWeight="bold">Horizontal</Text>
      <ScrollArea maxW="300px" orientation="horizontal" scrollbarVisibility="always">
        <Box whiteSpace="nowrap">
          {Array.from({ length: 5 }, (_, i) => (
            <Text key={i} fontSize="sm">{"Horizontal content ".repeat(15)}</Text>
          ))}
        </Box>
      </ScrollArea>
    </Box>
  </Stack>
);
```

### Visibility

Use `scrollbarVisibility` to choose when the scrollbar is shown:

- `auto-hide` (default): the bar appears when the pointer enters the area or
  when the content scrolls, then hides after a short idle delay. While the
  pointer stays inside, only scrolling reveals it again.
- `always`: the bar stays visible and the viewport reserves a gutter so it
  never overlays content.

```jsx live
const App = () => (
  <Stack gap="600" direction="row">
    <Box>
      <Text fontSize="sm" mb="200" fontWeight="bold">Auto-hide (default)</Text>
      <ScrollArea maxH="120px" w="200px">
        {Array.from({ length: 15 }, (_, i) => (
          <Text key={i} fontSize="sm">Line {i + 1}</Text>
        ))}
      </ScrollArea>
    </Box>
    <Box>
      <Text fontSize="sm" mb="200" fontWeight="bold">Always</Text>
      <ScrollArea maxH="120px" w="200px" scrollbarVisibility="always">
        {Array.from({ length: 15 }, (_, i) => (
          <Text key={i} fontSize="sm">Line {i + 1}</Text>
        ))}
      </ScrollArea>
    </Box>
  </Stack>
);
```

### Appearance

Use `variant` to choose the scrollbar's visual style. It is independent of
`scrollbarVisibility`, so any look can also be `always` visible.

- `solid` (default): grey track, thumb fills its width.
- `inset`: grey track with an inset, floating pill thumb.
- `overlay`: no track — only the thumb shows.
- `glass`: translucent, frosted track that blurs the content behind it.

```jsx live
const App = () => (
  <Stack gap="600" direction="row" flexWrap="wrap">
    {["solid", "inset", "overlay", "glass"].map((variant) => (
      <Box key={variant}>
        <Text fontSize="sm" mb="200" fontWeight="bold">{variant}</Text>
        <ScrollArea
          maxH="120px"
          w="180px"
          variant={variant}
          scrollbarVisibility="always"
        >
          {Array.from({ length: 15 }, (_, i) => (
            <Text key={i} fontSize="sm">Line {i + 1}</Text>
          ))}
        </ScrollArea>
      </Box>
    ))}
  </Stack>
);
```

### Size

Control the scrollbar thickness. Available sizes: `xs`, `sm` (default), `md`, `lg`.

```jsx live
const App = () => (
  <Stack gap="600" direction="row" flexWrap="wrap">
    {["xs", "sm", "md", "lg"].map((size) => (
      <Box key={size}>
        <Text fontSize="sm" mb="200" fontWeight="bold">{size}</Text>
        <ScrollArea maxH="120px" w="180px" size={size} scrollbarVisibility="always">
          {Array.from({ length: 15 }, (_, i) => (
            <Text key={i} fontSize="sm">Line {i + 1}</Text>
          ))}
        </ScrollArea>
      </Box>
    ))}
  </Stack>
);
```
