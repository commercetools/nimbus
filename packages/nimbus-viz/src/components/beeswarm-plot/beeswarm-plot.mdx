## Beeswarm Plot

<ChartMeta />

Every sample kept visible, packed without overlap.

```jsx live
const rand = (i) => { const x = Math.sin(i * 12.9898 + 78.233) * 43758.5453; return x - Math.floor(x); };
const values = Array.from({ length: 220 }, (_, i) =>
  Math.round(50 + ((rand(i) + rand(i + 60) + rand(i + 130)) / 3 - 0.5) * 70)
);

const App = () => (
  <ChartThemeProvider mode="light">
    <ResponsiveContainer height={280}>
      {(width, height) => <BeeswarmPlot width={width} height={height} values={values} />}
    </ResponsiveContainer>
  </ChartThemeProvider>
);
```

### Import

```tsx
import { BeeswarmPlot, ChartThemeProvider, ResponsiveContainer } from "@commercetools/nimbus-viz";
```
