# Research notes

Standalone research artifacts that inform Nimbus component design and are
expected to **outlive** the OpenSpec change that first cites them. An OpenSpec
change directory is archived once it is applied; research that stays relevant to
later phases (or to sibling components) lives here instead, so it remains
discoverable after the originating change is archived.

Each file is named `<topic>.research.md` and records the sources consulted, the
claims that survived verification, and the conclusions that fed a design
decision.

## Contents

- **`list-box-variants.research.md`** — ListBox visual variants & usage
  research. Grounds the ListBox OpenSpec proposal and the later Phase 3 Select /
  ComboBox compositions. Cited from `openspec/changes/add-list-box-component/`.
